# 🔐 Generador de Contraseñas Seguras

> Crea contraseñas seguras en un clic.

Aplicación web interactiva desarrollada con **HTML, CSS y JavaScript** que permite generar claves aleatorias, personalizadas y de alta seguridad mediante una interfaz limpia e intuitiva.

---

## ✨ Características
* **Longitud ajustable**: Control deslizante para definir la extensión de la contraseña entre 6 y 64 caracteres.
* **Opciones personalizables**:
  * 🔠 Mayúsculas (`A-Z`)
  * 🔢 Números (`0-9`)
  * 🔣 Símbolos (`!@#$%`)
* **Indicador de Seguridad**: Evaluación visual del nivel de fortaleza de la clave.
* **Copia al portapapeles**: Botón rápido para copiar la clave generada con un solo clic.
* **Diseño moderno**: Interfaz responsiva con tema oscuro y degradados.

---

## 🛠️ Tecnologías
* **HTML5**: Estructura semántica de la aplicación.
* **CSS3**: Estilos con tema oscuro y controles personalizados.
* **JavaScript (ES6+)**: Algoritmo de generación aleatoria y manejo de eventos.

---

## 🚀 Cómo ejecutarlo
1. Clona o descarga los archivos del repositorio.
2. Abre el archivo `index.html` en cualquier navegador web.
3. Elige los parámetros deseados y haz clic en **Generar contraseña**.

Enlace de la apliación: https://chavestacaro-ui.github.io/generador-de-contrase-as/
